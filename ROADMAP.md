# 🗺️ HubSynk Roadmap

This document outlines the planned features and improvements for future versions of HubSynk.

> Have a suggestion? Open an [Issue](https://github.com/saulomgg/HubSynk/issues) or start a [Discussion](https://github.com/saulomgg/HubSynk/discussions)!

---

## ✅ v1.0 — Current Release

- [x] Python Hub — manage Python environment via GUI
- [x] Official `.hubsynk` packages with RSA 4096 + SHA-256 verification
- [x] Custom `.exe` and `.py` tool support
- [x] GitHub repository integration (download & run)
- [x] Favorites, search, and modern Fluent Design UI
- [x] StampSynk DevTools for signing and packaging tools

---

## 🔜 v1.1 — Quality of Life

- [ ] **Auto dependency installer** — detect and install missing Python libraries automatically when launching a tool
- [ ] **Tool descriptions** — show description and version on tool cards
- [ ] **Sort & filter options** — sort tools by name, date added, or type
- [ ] **Dark / Light theme toggle**
- [ ] **Drag and drop** — drag `.exe`, `.py` or `.hubsynk` files directly into HubSynk to add them

---

## 🚀 v1.5 — GitHub & Catalog

- [ ] **Online catalog** — HubSynk reads `official-tools/catalog.json` from GitHub automatically and shows available tools to install
- [ ] **One-click install from catalog** — browse and install official tools directly from the interface without downloading manually
- [ ] **GitHub auto-install dependencies** — read `requirements.txt` from downloaded repositories and install automatically
- [ ] **Tool updates** — detect when an installed official tool has a newer version available

---

## 🌟 v2.0 — Major Update

- [ ] **Auto-updater** — HubSynk checks for new versions on startup and updates itself
- [ ] **Tool ratings & notes** — add personal notes and ratings to tools
- [ ] **Multi-key support** — support multiple trusted developers (multiple public keys)
- [ ] **Modern UI rewrite** — migrate from Tkinter to CustomTkinter or PyQt6 for a more polished interface
- [ ] **Portable mode** — run HubSynk without installing (USB-friendly)
- [ ] **Tool categories & tags** — organize tools by category (Video, Audio, Productivity, etc.)

---

## 💡 Ideas Under Consideration

- Plugin system for extending HubSynk functionality
- Community tool repository (submit your own `.hubsynk` tools)
- CLI version for power users
- macOS / Linux support
