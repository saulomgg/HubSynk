# Official HubSynk Tools

Esta pasta contém os pacotes `.hubsynk` das ferramentas oficiais.

Todos os pacotes aqui são **assinados digitalmente** (RSA 4096 + SHA-256)
e verificados automaticamente pelo HubSynk na instalação.

## Como instalar uma ferramenta

1. Abra o HubSynk
2. Clique em **➕ Add Official Tool**
3. Selecione o arquivo `.hubsynk` desejado

## Catálogo

O arquivo `catalog.json` lista todas as ferramentas disponíveis.
Futuramente o HubSynk poderá lê-lo automaticamente para exibir
as ferramentas disponíveis diretamente na interface.
